# 티켓팅 연습 페이지 — 요구사항

## 서비스 개념

매 3분마다 열리는 티켓팅 대기열을 실제와 동일한 흐름으로 반복 연습하는 앱.
하루 기준으로 회차가 누적된다. 최대 300명 입장, 100석 (A/B 구역 각 50석).

---

## 모드 정의

### 모드 1: 티켓팅 연습 (3분 단위)
- 매 3분 정각마다 새 회차 오픈 (자정 기준 3분 단위)
- 하루 자정(00:00)부터 3분마다 1회차 증가
- 최대 300명 입장 제한, 100석 (A/B 구역 각 50석)
- **사이클**: 대기열 1분 → 좌석 선택 1분 30초 → 쿨다운 30초
- 플로우: **대기(standby) → 대기열 1분 → 좌석 선택 1분 30초 → 결과**
  - standby: 다음 3분 경계까지 카운트다운. 경계 도달 시 1분 window 내에 "대기열 입장" 버튼 활성화
  - queue: 가짜 대기번호 카운트다운 1분 (자동 전이)
  - selecting: 1분 30초 안에 좌석 선택
  - confirming: 선택 좌석 확인 후 예매 확정
  - result: 소요 시간 표시 + 다음 회차 도전

### 모드 2: 대기열 반응속도 연습 (solo)
- 10초마다 대기열 버튼 활성화
- 버튼 클릭까지 걸린 ms 측정
- 최근 10회 기록 및 평균/최고 표시

### 모드 3: 좌석 선택 속도 연습 (solo)
- 시작 버튼 → 좌석 클릭 → 예매 확정까지 소요 시간 측정
- 구간 분리: 좌석 클릭까지 / 확정까지
- 최근 10회 기록 및 평균/최고 표시

## 기능 요구사항

### Must Have
| ID | 기능 | 설명 |
|----|------|------|
| F-01 | 모드 선택 | 홈에서 티켓팅 연습 / 혼자 연습하기 선택 |
| F-02 | 회차 표시 | 오늘 기준 3분 단위 회차 번호 표시 |
| F-03 | 카운트다운 | 다음 오픈까지 MM:SS 실시간 표시 |
| F-04 | 대기열 시뮬레이션 | 가짜 대기번호(1~300) 카운트다운으로 실제 대기 경험 제공 |
| F-05 | 좌석 선택 | 구역/행/번호 시각화, available/booked 상태 표시 |
| F-06 | 예매 확정 | 좌석 선택 후 확정 버튼 → 결과 표시 |
| F-07 | 소요 시간 측정 | 좌석 선택 시작~예매 완료까지 초 단위 측정 |
| F-08 | 타임아웃 | 1분 30초 초과 시 자동으로 결과 페이지 전환 |

### Nice to Have
| ID | 기능 | 설명 |
|----|------|------|
| F-10 | 기록 저장 | 회차별 소요 시간 로컬 저장 및 히스토리 표시 |

| F-12 | 동시성 테스트 | 같은 좌석에 동시 요청 시 하나만 성공하는 시나리오 |
| F-13 | 혼자 연습하기 기록 | 대기열 연습·좌석 연습의 시도별 기록을 로컬에 저장하고, 평균값과 함께 표시. 주(週) 단위로 자동 초기화 |

## 비기능 요구사항
- 회차 계산은 로컬 시간 기준 (한국 사용자 대상)
- 새로고침 시 standby 단계로 초기화 (Phase 1)
- 백엔드 없이 프론트 단독으로 완전히 동작해야 함 (Phase 1)
